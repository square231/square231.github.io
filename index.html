Personal Software

Personal software, built for one person's own devices and own use.

Cherie Browser

A personal web browser for iPhone, built on WKWebView. It has a URL field for entering addresses directly, search for finding pages on the web, and bookmarks for the sites its user returns to. It renders the page at the address entered — nothing more, nothing in between. It is a small, single-purpose app, developed for personal use.

Chérie Mothership

A personal device-management app for iPhone. It pulls together tools for looking after one phone and one home — notifications, media, files, and everyday utilities — in one place, under the user's control.
